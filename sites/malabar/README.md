# Malabar coast

Tyndis, Muziris, Nelkynda and Bakarē, on the coast of Kerala.

Everything done on this coast before the reorganisation of November 2026 is in
`archive/docs/FINDINGS.md` and `archive/docs/new_findings_v2.md`. The code that
produced it is live in `quantitative/src/`, and its data
is in `data/`.

| Folder | What |
|---|---|
| `readings/` | PDFs, split into `material/`, `coastline/` and `general/`. Gitignored |
| `material/` | Qualitative analysis of the pottery and finds: `notes.md`, `data/`, `figures/` |

The coastline, river and voyage work for this site is in `quantitative/`, which
both sites share.
